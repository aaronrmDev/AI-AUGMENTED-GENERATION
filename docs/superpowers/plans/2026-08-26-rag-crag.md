# RAG CRAG (Corrective RAG) Implementation Plan

**Goal:** Implement CRAG as a `Retriever` decorator, prove its impact with a live
Ollama/Qdrant measurement, and merge to `develop`.

**Architecture:** `CorrectiveRetriever(Retriever)` wraps an inner `Retriever` and a
`ChatModel`. Per the design spec, it evaluates each retrieved result's relevance with one
`complete()` call, filters to the relevant subset on a strict majority, or triggers a
single-shot corrected re-search otherwise.

**Tech Stack:** Same as every prior batch — Python, Ollama (qwen3.5), Qdrant, pytest.

**Spec:** `docs/superpowers/specs/2026-08-26-rag-crag-design.md`

## Global Constraints

- Every `ChatModel` call for a non-QA prompt (relevance judgment, query refinement) MUST
  use `complete()`, never `generate()` — Batch C's final review found `generate()`'s
  hardcoded RAG-answering system prompt silently breaks any non-QA prompt routed through
  it.
- Every new scenario entrypoint script needs a name unique across the whole
  `evaluation/scenarios/` tree — two prior batches broke `mypy evaluation/` by both
  naming a script `run_comparison.py`. This batch's script is
  `run_crag_comparison.py`.
- Any value computed only inside a `treatment()` closure must never be built directly
  into the `notes=` kwarg passed to `RunComparison.execute()` — that kwarg is evaluated
  before `execute()` calls `treatment()`. Accumulate into a closed-over list/variable,
  call `execute()`, then `dataclasses.replace(result, notes=...)` afterward.
- `DocumentRepository`'s fake in the new scenario script must implement all 5 abstract
  methods (`save_document`, `update_document_status`, `save_chunks`,
  `get_chunks_for_tenant`, `get_chunk_by_id`).

**Design for the query set:** CRAG's whole value proposition is filtering out noisy/
irrelevant retrieved material before it reaches the LLM. A corpus this small (14 chunks
from one document) makes it hard to manufacture genuinely irrelevant top-k results for
a well-targeted query — so, matching this project's own "prove it, don't assume it"
standard, the query set includes:
- 5 RAG.md-grounded questions (same discipline as Batch C: verbatim-quoted, verified
  against the live file) that a plain vector search should answer well already —
  measuring whether CRAG's relevance filter/correction avoids regressing an
  already-good retrieval.
- 2 deliberately vague/adversarial questions using vocabulary NOT prominent in RAG.md
  (testing whether a bare vector search pulls in weakly-related chunks that CRAG's
  relevance check would then filter or correct away) — this is where CRAG's actual value
  should show up, if it shows up at all; a null/negative result here is reported
  honestly, not massaged.

```python
"""Manual comparison runner for the RAG CRAG batch. Not pytest-collected (no
test_* function at module level) -- mirrors this project's established
pattern for scripts that make real model calls and are run by hand.

Usage (PYTHONPATH=. is required):
    PYTHONPATH=. uv run python evaluation/scenarios/rag-crag/run_crag_comparison.py
"""
import asyncio
import uuid
from pathlib import Path

import ollama

from evaluation.application.run_comparison import RunComparison
from evaluation.domain.entities import Answer
from evaluation.infrastructure.markdown_report import render
from evaluation.infrastructure.ollama_judge import OllamaJudge
from evaluation.scenarios.loader import load_scenario
from src.rag.application.answer_question import AnswerQuestion
from src.rag.application.search_documents import SearchDocuments
from src.rag.application.upload_document import UploadDocument
from src.rag.domain.entities import Chunk, Document
from src.rag.domain.ports import DocumentRepository
from src.rag.infrastructure.corrective_retriever import CorrectiveRetriever
from src.rag.infrastructure.fixed_size_chunker import FixedSizeChunker
from src.rag.infrastructure.local_file_storage import LocalFileStorage
from src.rag.infrastructure.ollama_chat_model import OllamaChatModel
from src.rag.infrastructure.qdrant_vector_store import QdrantVectorStore
from src.rag.infrastructure.sentence_transformers_embedder import SentenceTransformersEmbedder
from src.rag.infrastructure.text_extractor import TextExtractor

_SCENARIO_DIR = Path(__file__).parent
_MODEL_CONFIG = "qwen3.5, Ollama"


class _InMemoryDocumentRepository(DocumentRepository):
    def __init__(self) -> None:
        self._chunks: list[Chunk] = []

    async def save_document(self, document: Document) -> None:
        pass

    async def update_document_status(self, document_id, status, chunk_count) -> None:
        pass

    async def save_chunks(self, chunks: list[Chunk], tenant_id: uuid.UUID) -> None:
        self._chunks.extend(chunks)

    async def get_chunks_for_tenant(self, tenant_id: uuid.UUID) -> list[Chunk]:
        return self._chunks

    async def get_chunk_by_id(self, chunk_id: uuid.UUID) -> Chunk | None:
        return next((c for c in self._chunks if c.id == chunk_id), None)


async def _run() -> None:
    scenario = load_scenario(_SCENARIO_DIR)
    embedder = SentenceTransformersEmbedder()
    vector_store = QdrantVectorStore("http://localhost:6333")
    await vector_store.ensure_collection()
    chunker = FixedSizeChunker()

    ollama_client = ollama.AsyncClient(host="http://localhost:11434")
    chat_model = OllamaChatModel(client=ollama_client, model_id="qwen3.5")

    tenant_id = uuid.uuid4()
    document_repository = _InMemoryDocumentRepository()
    upload = UploadDocument(
        document_repository=document_repository,
        embedding_model=embedder,
        vector_store=vector_store,
        chunker=chunker,
        extractor=TextExtractor(),
        file_storage=LocalFileStorage(),
    )
    corpus_bytes = (_SCENARIO_DIR / "corpus" / "rag.md").read_bytes()
    document = await upload.execute(tenant_id=tenant_id, filename="rag.txt", content=corpus_bytes)
    print(f"Uploaded corpus: {document.chunk_count} chunks")

    vector_retriever = SearchDocuments(embedding_model=embedder, vector_store=vector_store)
    crag_retriever = CorrectiveRetriever(inner=vector_retriever, chat_model=chat_model)

    plain_answerer = AnswerQuestion(search_documents=vector_retriever, chat_model=chat_model, top_k=5)
    crag_answerer = AnswerQuestion(search_documents=crag_retriever, chat_model=chat_model, top_k=5)

    async def baseline(question: str) -> Answer:
        result = await plain_answerer.execute(tenant_id=tenant_id, question=question)
        context = "\n\n".join(s.content for s in result.sources)
        return Answer(text=result.answer, input_tokens=0, output_tokens=0, context=context)

    async def treatment(question: str) -> Answer:
        result = await crag_answerer.execute(tenant_id=tenant_id, question=question)
        context = "\n\n".join(s.content for s in result.sources)
        return Answer(text=result.answer, input_tokens=0, output_tokens=0, context=context)

    def success_check(question: str, answer: Answer) -> bool:
        # per-question checks derived from queries.yaml's success_criterion,
        # same pattern as every prior batch's scenario script
        ...

    judge = OllamaJudge(client=ollama_client, model_id="qwen3.5")
    use_case = RunComparison(judge=judge, repeat_count=3)
    result = await use_case.execute(
        scenario_name=scenario.name,
        model_config=_MODEL_CONFIG,
        success_criterion="see evaluation/scenarios/rag-crag/queries.yaml",
        rag=True, cag=False, mag=False,
        notes=(
            f"corpus=docs/architecture/RAG.md, {document.chunk_count} chunks. "
            f"Baseline = plain vector search (SearchDocuments), Treatment = "
            f"CorrectiveRetriever-wrapped search. CAVEAT: qualitative judge is "
            f"Ollama/qwen3.5, not Claude (no API credit balance at run time) -- "
            f"self-grading-bias risk, same as every prior batch in this project."
        ),
        questions=[q.question for q in scenario.questions],
        baseline=baseline,
        treatment=treatment,
        success_check=success_check,
    )
    report_path = Path("evaluation/reports/rag-crag-crag.md")
    report_path.write_text(render(result), encoding="utf-8")
    print(f"Report written to {report_path}")


if __name__ == "__main__":
    asyncio.run(_run())
```
